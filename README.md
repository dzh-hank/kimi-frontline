# Kimi 战线（kimi-frontline）

一款单文件 HTML5 即时战略 + 塔防混合游戏：经营矿脉、建造防线、指挥部队，抵御从北部与东部裂隙涌来的敌人。

## 玩法

- 在已侦察区域自由建造；核心建筑提供建造范围，「中继站（B）」不受建造范围限制，可把防线推到前线
- 建错了可以随时拆除已完工建筑，返还 75% 资源（快捷键 Del / Backspace）
- 战役关卡全部解锁，遭遇战三档难度可选
- 支持移动端触控操作

## 本地运行

直接用浏览器打开 `index.html` 即可，无需服务器。
